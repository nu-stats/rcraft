# P9.1 Dialog-spec plugins (open → done) · 7½ h · no installs (see the format note)

**Goal:** a user adds a menu entry for any CRAN function with a text file, no Rust.

**Format:** one TOML file per dialog, in `<RCraft data folder>/plugins/`. Parse it with `toml_edit`, which is already in `Cargo.lock` (no new download). If a new crate is needed after all, ask the owner first.

```toml
menu = "Statistics > My tools > Robust regression"
about = "Robust linear regression with MASS::rlm"
needs = ["MASS"]
code = "{out} <- MASS::rlm({y} ~ {x}, data = {data})\nsummary({out})"
[[widget]]  # kinds: data, variable, variables, number, text, choice, check, output
kind = "variable"
name = "y"
label = "Outcome"
filter = "numeric"
```

**Build:**
- `crates/catalog/src/plugin.rs`, with an owned `PluginSpec`:
  - it parses and checks the file: every `{placeholder}` has a widget, the kinds are known, and the menu path is new;
  - each error names the line.
- The template fills in the user's choices, quoted by the same code the built-in specs use (`rcodegen`), so names with spaces stay safe.
- `crates/ui-egui/src/spec_dialog.rs` renders a `PluginSpec` with the same widgets as a static `Spec`. Factor the widget rendering so both use it; don't copy it.
- The menus load the plugins at start, plus Packages > Reload plugins. A bad file is skipped with a message in Results; it never crashes.

**Test:**
- `a_spec_file_becomes_a_dialog` and `a_bad_spec_file_is_refused_with_its_line`, unit tests in `plugin.rs`;
- `a_plugin_menu_runs_in_r` in `crates/engine/tests/plugins.rs`: a sample plugin for `stats::mad` runs and gives `mad()`'s value.

**Done:** the three tests are live.
