# P8.2 Installers (open → done) · 7½ h · decisions 2 and 3

**Build:** `.github/workflows/release.yml`, ported from StatCraft's own `release.yml` (the owner's code, so it can be ported as-is; adjust names and paths). It runs on a `v*` tag or by hand, and builds:

| System | Packages | Signing |
|---|---|---|
| Windows | MSI (WiX) and a portable zip | Azure Trusted Signing (`nustatssigning`), once decision 2's secrets are in `nu-stats/rcraft`; unsigned until then |
| macOS | Universal DMG (x86_64 + arm64 with `lipo`) | Signed and notarised once decision 3's Developer ID exists; unsigned until then |
| Linux | AppImage, deb, rpm, tar.gz | Not signed (the norm) |

**Smoke test:** each job installs or unpacks what it built and starts RCraft headless (`--version`, or the existing headless mode in `crates/ui-egui/src/headless.rs`). The job fails if it doesn't start.

**Done:**
- the file exists;
- a release run built every installer and each one started;
- the owner has seen that run.

Without decisions 2 and 3, the installers are unsigned; the owner decides whether that counts.
