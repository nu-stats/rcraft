# P6.12 Machine learning basics (open → done) · 2½ h · install tidymodels (decision 1)

**Build:** Statistics > Machine learning model, in a new `crates/catalog/src/ml.rs`. One dialog, four steps:
- **split:** `rsample::initial_split`, with a proportion and a seed; stratified optionally;
- **fit:** a `parsnip` linear or logistic regression (glmnet only if installed). A random forest only if `ranger` is installed; otherwise refused, naming the package;
- **tune:** `tune::tune_grid` over a penalty grid with v-fold cross-validation;
- **evaluate:** `yardstick` RMSE and R², or accuracy and ROC AUC, on the test set.

**Check** (there's no Stata analogue), by hand on a fixed split:
- the split's rows equal `sample` with the same seed, drawn the way rsample draws;
- the linear fit equals `lm` on the training rows;
- the RMSE equals the formula.

Add tidymodels to `ci.yml`.

**Test:** add `crates/engine/tests/ml.rs`.

**Done:** the entry `Machine learning model` is `Verified`.
