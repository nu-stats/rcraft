# P6.10 Structural equation models (open → done) · 2½ h · install lavaan (decision 1)

**Build:** Statistics > Structural equation model, in a new `crates/catalog/src/sem.rs`.

**The dialog:**
- the model as lavaan syntax in a text box, with a helper that adds measurement (`=~`) and regression (`~`) lines from variable pickers;
- estimator ML;
- standardised estimates optional;
- fit indices: chi², RMSEA, CFI, TLI, SRMR.

**R:** `lavaan::sem`, then `summary(fit, fit.measures = TRUE, standardized = TRUE)`.

**Stata 19 check:** `sem (L -> x1 x2 x3) (y <- L)` on made-up data; coefficients, SEs and chi² must match. Find lavaan's matching settings (`likelihood`, `mimic`) by running both, never by reading Stata's files.

Add lavaan to `ci.yml`.

**Test:** add `crates/engine/tests/sem.rs`.

**Done:** the entry `Structural equation model` is `Verified`.
