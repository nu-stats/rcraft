# P1.2 Portable R (open → done) · 7½ h · raise with the owner first (decision 4)

**Goal:** when no R is found, RCraft offers to download the pinned R.

**Build:** `crates/rhost/src/portable.rs`, plus a first-run dialog in the app.
- **The offer:**
  - shows the R version from `ENVIRONMENT`, the download size and R's licence (GPL-2 | GPL-3, the text shown);
  - nothing is fetched before the user's yes.
- **The pins:** in `ENVIRONMENT`, one line per system, with the URL and its SHA-256:
  - **Windows:** CRAN's `R-<ver>-win.exe`, run silently into RCraft's folder (`/VERYSILENT /DIR=...`);
  - **macOS:** CRAN's `.pkg` for the machine's architecture, expanded without admin (`pkgutil --expand-full`) into RCraft's folder;
  - **Linux:** Posit's prebuilt R for the distribution (`cdn.posit.co/r/<distro>/...tar.gz`), unpacked. On a distribution with no build, say so and point to the distribution's R.
- **Verification:** the SHA-256 is checked before anything runs. A mismatch deletes the file and says so.
- **After install:** `find_installs` finds it, and the session starts with it.
- The download runs on a worker with progress and Cancel, and the app never blocks (AGENTS.md's never-crash rules).

**Test:**
- `a_wrong_checksum_is_refused`, a unit test in `portable.rs` against a local file;
- `the_pinned_r_downloads_verifies_and_starts` in `crates/rhost/tests/portable.rs`. It's opt-in (`RCRAFT_LIVE_DOWNLOAD=1`), run once on each system in CI by hand, with the result recorded in `plan/status.d/P1.2.md`.

**Done:** both tests are live.
