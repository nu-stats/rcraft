# P9.3 Preferences (open → done) · 5 h · no installs

**Build:** an Edit > Preferences window, saved between runs. Store the file in RCraft's settings folder, the way `crates/rhost/src/recent.rs` stores recent files; follow that file's pattern.

| Setting | Effect |
|---|---|
| Code style: tidyverse or base R | The default `Style` every dialog writes (`rcodegen::dialog::Style`); a dialog that has only one style keeps it |
| Package snapshot date | The dated repository Packages installs from (today it comes from `ENVIRONMENT`; the preference overrides it, and Reset goes back) |
| Theme: light, dark or follow the system | `crates/ui-egui/src/look.rs` |
| Font size | `look.rs` |

**Test:**
- `preferences_survive_a_restart` in `crates/ui-egui/src/prefs.rs`: write, read back, and fall back to the defaults on a bad file;
- `the_preferred_style_reaches_every_dialog` in `crates/rcodegen/src/dialog.rs`: every spec in `all_specs()` writes in the preferred style when it offers that style.

**Done:** both tests are live.
