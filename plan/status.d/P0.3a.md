## STATUS

## P0.3a: the roadmap's % complete, worked out by the machine, 2026-11-23

- `cargo xtask progress` reads `plan/progress.txt`, one line per roadmap task with its state, its planned day and its checks. A check is a catalog entry that must be `Verified`, a test that must exist and not be ignored, a file, or the owner's sign-off. It prints the figure, the pace against the planned days, the day the plan reaches 98%, and every task left. `cargo xtask ci` runs it with `--check`, and on GitHub Actions the report goes into each job's summary.
- A task whose checks hold counts as done. A line that says `done` while a check fails fails CI, so the figure can't be typed or nudged.
- On 23 Nov: 89 of 108 tasks, 82.4% (85 done, 8 part done, 15 not started). The planned days reach 98% (106) on 8 Dec.
- `plan/work-orders/` has one order for each task left: what to build, where, how it is proved, and the hours. Its README lists the owner's five decisions, asked once.
- `plan/DECISIONS.md` collects the owner's standing rules.
