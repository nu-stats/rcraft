# RCraft manual

RCraft is a window for R. You click through menus, and RCraft writes the R code, runs it in your own copy of R and shows what came back. The manual is nine short pages.

- [Getting started](getting-started): finding R, the panes, your first data file and your first model.
- [The menus](menus): what each menu holds.
- [The Data menu](data-dialogs): changing variables and rows, combining and reshaping data frames.
- [The Statistics menu](statistics-dialogs): summaries, tests and models, and what to do with a fitted model.
- [The Graphs menu](graphs-dialogs): the plots, and the Graph tab that shows them.
- [The Data tab and Properties](data-and-properties): looking at the rows, the Variables and Objects tabs, and Properties.
- [The Command window](command-window): typing commands, history, Tab completion, Stata mode and help.
- [Packages](packages): finding, installing and updating R packages, and keeping a list for a project.
- [Projects and reporting](projects-and-reporting): saving your work, the session's report and exporting a table.

## Finding things

Type a word in the box at the top of this window and press Search: the pages of this manual and R's own help pages are listed together, best fit first. With no R running, the manual alone is searched. In the Command window, `help rcraft` opens this page.

The manual works with no network. R's own help for a function is one click away from any page that names it, for example [lm](help:lm).
